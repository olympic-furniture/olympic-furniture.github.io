# מדריך עריכת האתר למשפחה

אפשר לערוך את הטקסטים, התמונות והרהיטים דרך [Pages CMS](https://app.pagescms.org/). הקישור "עריכת האתר" בתחתית האתר מוביל לאותו עורך. אין צורך לערוך קוד.

## כניסה ראשונה

העורך עדיין דורש חיבור לחשבון GitHub של הארגון. מנהל הארגון צריך לפתוח את [קישור התקנת Pages CMS](https://github.com/apps/pages-cms/installations/new), לבחור בארגון `olympic-furniture`, לבחור **Only select repositories**, ולסמן רק את `olympic-furniture.github.io`. לאחר ההתקנה, נכנסים לעורך עם חשבון GitHub שיש לו הרשאת עריכה במאגר.

בעורך בוחרים את הארגון, את המאגר `olympic-furniture.github.io`, ואת הענף `main`. הרשאה לעריכת האתר ניתנת דרך הרשאות GitHub. אין למסור סיסמאות לבני משפחה אחרים; כל עורך משתמש בחשבון שלו.

## שינוי רהיט קיים

1. פותחים "רהיטים בגלריה" ובוחרים את הרהיט.
2. משנים שם, קטגוריה ותיאור. התיאור הוא טקסט רגיל. כותבים רק פרטים שהעסק אישר, ולא הבטחות לגבי מלאי, משלוח או אחריות שלא נבדקו.
3. בוחרים תמונה קיימת או מעלים תמונה חדשה. כדאי להשתמש בתמונה ברורה של הרהיט עצמו, ללא מחיר ישן שמופיע בתוך התמונה.
4. אם יש מחיר עדכני שאושר, מקלידים מספר בשקלים, למשל `2400` או `2400.50`. אין להקליד ₪, פסיקים או מילים. אם אין מחיר מאושר, משאירים את השדה ריק. אין להקליד אפס.
5. מפעילים "המחיר מתחיל מ־" רק כאשר העסק אישר שזהו מחיר התחלתי. מחיר ללא הסימון מופיע כמחיר הרהיט.
6. "סדר הצגה" חייב להיות מספר שלם מאפס ומעלה. מספר קטן מוצג קודם.
7. שומרים באמצעות כפתור השמירה בעורך. שמירה בענף `main` מתחילה בדיקה ופרסום אוטומטיים.

## הוספת רהיט

ב"רהיטים בגלריה" יוצרים פריט חדש. משלימים שם, אחת משבע הקטגוריות, תמונה, תיאור וסדר הצגה. אפשר להשאיר מחיר ריק. שם הקובץ נוצר אוטומטית עם תאריך ושם הרהיט; אם משנים אותו בזמן היצירה, יש לבחור שם ייחודי ולהשאיר את הסיומת `.json`.

בתחילה משאירים "להציג באתר" כבוי ושומרים. כך אפשר לבדוק את התוכן לפני פרסום. לאחר אישור התמונה, התיאור והמחיר, מפעילים "להציג באתר" ושומרים שוב. כדי להסתיר רהיט קיים, מכבים את אותה אפשרות ושומרים. עדיף להסתיר רהיט לפני שמחליטים למחוק אותו.

המאגר ב־GitHub הוא ציבורי. גם טיוטות ותמונות שהועלו אליו נגישות ב־GitHub. האפשרות "להציג באתר" קובעת אם הרהיט מופיע בגלריה, ולכן אין להעלות מידע אישי או חסוי.

## שינוי פרטי העסק והסיפור

פותחים "פרטי העסק ותוכן האתר". אפשר לערוך את כותרת הפתיחה, הטקסט, הסיפור המשפחתי ואפשרויות ההתאמה האישית. כל פריט ב"פסקאות הסיפור המשפחתי" הוא פסקה אחת. בכל אפשרות התאמה יש שם והסבר קצר. יש להשאיר לפחות פסקת סיפור אחת ואפשרות התאמה אחת.

שומרים טלפונים כטקסט עם האפס בתחילת המספר. את הכתובת כותבים בתבנית `האורזים 6, נתניה`, עם פסיק לפני העיר. קישורי מפות, ווייז ופייסבוק מתחילים ב־`https://`.

וואטסאפ, דואר אלקטרוני ושעות פתיחה הם שדות אופציונליים. משאירים אותם ריקים עד שהעסק מאשר מידע עדכני. אין להסיק מספר וואטסאפ מהטלפון הקווי. שינוי שם העסק, טלפון, כתובת או טקסט הפתיחה מעדכן גם את מידע האתר למנועי החיפוש בפרסום הבא.

## תמונות מותרות

משתמשים בתמונות העסק שהמשפחה אישרה, בתמונת המייסדים שסופקה, ובתמונות הפייסבוק מהתקופה המאושרת 15 בנובמבר 2023 עד 17 בנובמבר 2025, כולל שני התאריכים. לפני הוספת תמונת פייסבוק נוספת, בודקים את תאריך הפרסום. [רשימת המקורות](image-sources.md) מתעדת את התמונות שכבר אושרו.

העלאת תמונות שומרת קבצים בתוך `public/images`. העורך כותב לתוכן קישור מקומי שמתחיל ב־`/images/`. אין להדביק קישור זמני של פייסבוק במקום העלאה. רצוי להשתמש ב־WebP, JPG או PNG ולצמצם תמונות גדולות לפני ההעלאה. אין למחוק תמונה שמשמשת רהיט, את הפתיחה או את הסיפור המשפחתי.

## בדיקה אחרי שמירה

ב[לשונית Actions של המאגר](https://github.com/olympic-furniture/olympic-furniture.github.io/actions) מחפשים את הריצה **Verify and deploy site** של השמירה האחרונה. מחכים שתסתיים בהצלחה ואז פותחים את [האתר](https://olympic-furniture.github.io/) ומרעננים. בודקים את הרהיט בקטגוריה הנכונה, את התמונה ואת המחיר גם בטלפון.

אם הבדיקה נכשלת, האתר נשאר בגרסה הקודמת שהצליחה. מתקנים בעורך את הבעיה ושומרים שוב. הודעת בדיקת התוכן מציינת את הקובץ והשדה הבעייתיים. סיבות נפוצות הן מחיר שאינו מספר חיובי, סדר הצגה שאינו מספר שלם, שדה חובה ריק או תמונה שנמחקה. אם התיקון אינו ברור, מעבירים למי שמתחזק את האתר קישור לריצה שנכשלה. היסטוריית GitHub שומרת את השינויים ומאפשרת למתחזק לשחזר גרסה קודמת.

לפני הפרסום הראשון עוד נדרשים בדיקת הנוסח העברי על ידי סבא, אימות הפרסום החי וחיבור העורך. מחירים, שעות פתיחה ותנאי משלוח יתווספו רק לאחר אישור העסק.
